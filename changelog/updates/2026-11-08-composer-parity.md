**The Mac message composer follows the iPhone design.** A compact plus menu, message capsule and circular send or edit control share the same Apple components, spacing and glass treatment. The attachment icon stays small. Reply and edit panels use the same style, and a photo or file without a caption shows its media label in the reply bar. Return sends; Shift+Return starts a new line. Android uses the same composer icon size and keeps its larger touch targets.
