**Bipe for Mac has a native window toolbar.** The account photo, Chats, Groups and You sit in the toolbar, search is the sidebar field, and the open chat's name sits in the toolbar. A selected favourite now shows as selected. New messages no longer pull you away from older ones, and a chat sends a read receipt only when you are at the latest message.
